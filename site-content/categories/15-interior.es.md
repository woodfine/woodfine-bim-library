card_desc: Objetos BIM de mobiliario y restricciones de circulación para la elaboración de Key Plans
---
Interior — las piezas de mobiliario a partir de las cuales se elabora un Key Plan, y las holguras de circulación que exige cada una.

Objetos BIM de mobiliario y restricciones de circulación usados para elaborar Key Plans. Cada token de mobiliario lleva datos de producto del fabricante — dimensiones, holgura, SKU, peso, clase IFC y URL de origen — obtenidos de las páginas de producto de Steelcase y Coalesse. Los tokens de circulación llevan la referencia normativa de accesibilidad aplicable y los umbrales espaciales (ASR A1.2, DIN 18040, ArbStättV §12), usados para la validación de restricciones al elaborar un Key Plan.
